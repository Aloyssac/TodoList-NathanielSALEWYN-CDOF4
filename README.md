# TodoList Application

This project is a console-based ToDo List application written in Python. It allows users to manage their tasks by adding, viewing, and deleting them through a simple interface.

## Features
- View all tasks
- Add a new task
- Delete an existing task
- Keep the tasks in a .json file

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/todolist-app.git
   cd todolist-app
   ```

2. Install the application:
   ```bash
   python3 setup.py install
   ```

3. Run the application:
   ```bash
   python3 todolist_app.py
   ```
